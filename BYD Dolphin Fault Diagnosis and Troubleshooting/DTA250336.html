Conventional fault diagnosis

Visual inspection

  1. Confirm the customer's problems.

  2. Visually inspect for obvious signs of mechanical damage and collision deformation.

  3. If the problem observed or raised is obvious and the cause has been found, the cause must be corrected before proceeding to the next step.

  4. If the visual inspection is passed, identify the fault and refer to the Fault Symptoms Table.

Conventional Fault Symptoms Table

Symptoms Possible causes Recommended maintenance measures
Rear suspension noise during driving

  1. Loose fasteners of rear suspension

  2. Rear shock absorber

  3. Rear suspension component bushing

  4. Rear coil spring rubber base

  1. Check the rear suspension fasteners. If abnormal, tighten or replace damaged components.

  2. Check the shock absorber rubber base for wear. If abnormal, replace the damaged components of shock absorber.

  3. Check the rear suspension component bushing, and replace it if abnormal.

  4. Check the rear coil spring rubber base, and replace the rear coil spring if abnormal.
Rear suspension too soft or too hard

  1. Wheels, tires, tire pressure

  2. Rear shock absorber

  3. Rear coil spring rubber base

  1. Check the front suspension components. If abnormal, repair or replace damaged components.

  2. Check the rear shock absorber rubber base for wear. If abnormal, replace the damaged components of rear shock absorber.

  3. Check the rear coil spring rubber base, and replace the rear coil spring if abnormal.
