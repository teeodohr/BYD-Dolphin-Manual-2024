System descriptions

Overview

The infotainment system includes 4G network, PAD unit, Bluetooth phone, smart voice recognition, vehicle-infotainment interaction, on-board radio, USB, SD card assembly, audio and video equipment interface, image system and other functions.

Main components:

USB interface assembly

It includes 2 USB interfaces, of which only 1 USB interface supports audio and video file reading, and both USB interfaces can be used for charging handheld devices.

4G/WIFI/BT/GPS antenna

It supports 4G internet access and Wi-Fi connection to phones, among other functions.

EDR camera

  • Loop recording: When the memory card space is insufficient, the recorder will automatically overwrite the oldest videos to enable continuous loop recording.

  • Emergency recording: In the event of a collision or scratch, pressing the emergency button will automatically lock the video recorded 4 to 7 minutes prior to the accident, preventing it from being overwritten.

  • Collision recording: Once the recorder is activated and in recording mode, it will automatically enable collision detection. In the event of a severe accident, the recorder will automatically save an important segment of the recorded video capturing the accident. This specific recording will not be overwritten or deleted.

Panoramic camera

It includes two main functions: 2D panoramic view and transparent panoramic view. In R gear, these functions will be triggered automatically. Users can also activate and enable these functions manually by pressing the hard button on the steering wheel or the APP soft button on the touchscreen homepage. The image is input through 720P high-definition cameras and transmitted through the LVDS interface at a rate of 30 frames per second.

Rearview camera

It is mainly used to provide the user with a reversing image during reversing, to help the user complete parking faster. The user can use this function by turning on APP button on the touchscreen homepage if necessary or by shifting into R gear.

Multi-purpose camera assembly

  • It can assist the radar in identifying stationary vehicles ahead and remind the driver of active deceleration at a suitable distance, so as to avoid collision with such vehicles.

  • The multi-purpose camera can assist the radar in identifying the vehicle ahead which runs inside the current lane and has a coincident trajectory with the current vehicle as the target, and allow the driver to follow the target in cruise control mode.

  • The multi-purpose camera and the radar can timely identify the vehicles which run on both sides and try to change to the current lane as targets, and allow the driver to brake when necessary.

  • The multi-purpose camera and radar can identify pedestrians ahead in time, so that the vehicle can completely avoid possible accidents.
