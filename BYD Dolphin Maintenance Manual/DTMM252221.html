Color description in the figure

Figures will be used in some parts of this manual for description purpose, where figures may use multiple colors to express different meanings. The following table shows the possible colors and corresponding meanings.

Color Description
Purple: key parts that need to be highlighted during operation, such as the connection of lines or pipelines (such as connectors and pipeline joints), fasteners (such as bolts, nuts, screws, clips, and clamps).
Blue: the target or main components to be introduced, such as wheel assembly, seat assembly and control unit.
Green: the first replacement component, which needs to be removed or installed before removal or after installation of the target or main components. The same applies to components that need to be disassembled or assembled before disassembly or after assembly of the target or main components.
Brown: the second replacement component, which needs to be removed or installed before removal or after installation of the target or main component. It follows the first replacement part in implementation sequence. The same applies to components that need to be disassembled or assembled before disassembly or after assembly of the target or main components. They follow the first replacement part in implementation sequence.
Gray: background object, which is not described or introduced, but is one of the elements of the overall environment and status of the figure.
Light blue: common tools, special tools or equipment that need to be specifically described.
Yellow: components that need to be highlighted during movement, disconnection, connection, adjustment and other operations.
Orange: high-voltage wiring harness or relevant parts. If the connector of high-voltage wiring harness is a key part that needs to be highlighted, it shall be indicated in purple.
