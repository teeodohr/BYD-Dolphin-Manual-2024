Systems Manual

Overview

For this model, in addition to the traditional mechanical key, the electronic smart key system is configured for this vehicle, thus enabling the driver who carries this key to open the door without any operation of the key via buttons.

The system is controlled by an smart key system control module in the left body control module. When the smart key system control module detects that the key is within a certain detection area, it will verify the key and send a running signal to the ECU that will perform corresponding actions.

The detection system is composed of 5 detection antenna assemblies and used for detecting the valid range in the vehicle and the certain range outside the vehicle.
