Calibration of Intelligent Power Braking System

Caution
After replacing the intelligent power braking system, the yaw rate sensor needs to be calibrated. Calibrate it according to the VDS prompts.

  1. Connect the VDS and enter the diagnostic system.

  2. Select “Passenger Car”.

  3. Select "DM/EV".

  4. Select the model.

  5. Select "Electric Fluid Preparation".

  6. Select "Calibration".

  7. Wheel exhaust operation. See Air Discharge of Brake System
