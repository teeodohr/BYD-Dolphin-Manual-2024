Terms

The following table shows the terms commonly used for maintenance descriptions in the Maintenance Manual, as well as use examples.

Terms

Use example

Remove

Remove parts (e.g., bolts, nuts, and screws)

Install

Install parts (e.g., bolts, nuts, and screws)

Remove and install

Remove and install parts (e.g., wheels)

Replace

Remove parts and install new ones (e.g., CV joint oil seals)

Disassemble

Disassemble disassembleable assemblies (e.g., side mirror assemblies and HVAC assemblies)

Assemble

Assemble the disassembled assemblies (e.g., side mirror assemblies and HVAC assemblies)

Test

Use tools or certain methods to measure the parameters and performance of systems/components (e.g., air tightness of high-voltage battery packs)

Calibrate

Use tools to calibrate parameters after system maintenance or replacement (e.g., ACC)

Match

Match parameters of system components for normal operation (e.g., smart keys)

Reset

Restore programs, circuits, or structures to initial states (e.g., subtotal mileage displayed on the instrument panel cluster, and clock spring)

Self-learning

Monitor and automatically correct system structures or parameters during system operation (e.g., tire pressure systems)

Programme

Use tools to update system program files (e.g., system programs)

Update

Change and replace system programs (e.g, updating system programs)

Upgrade

Update versions of system programs (e.g, upgrading system programs)

Take out

Directly take out parts, or directly take out parts after removing fasteners

Adjust

Adjust mechanical part states, system software parameters, etc., (e.g., door hinges and four-wheel alignment)

Unscrew

Loosen parts, but do not remove them (e.g., bolts and nuts)

Tighten

Tighten parts (e.g., bolts, nuts, and screws)

Pry out

Pry out parts with tools (e.g., A-pillar trim panels)

Disconnect

Separate two parts with a simple/quick connection (e.g., connectors and 12 V battery negative cables)

Connect

Connect two parts with a simple/quick connection (e.g., connectors and 12 V battery negative cables)

Open

Open parts that can be opened/closed (e.g., doors and hoods)

Close

Close parts that can be opened/closed (e.g., doors and hoods)

Detach

Remove fasteners with a simple/quick connection from their bodies (e.g., clips and tie wraps)

Lift down

Lift down parts posing challenges for a single person to move (e.g., seat assemblies)

Lift up

Use lifting equipment to move heavy objects from low to high (e.g., vehicles, powertrains and high-voltage batteries)

Lower

Use lifting equipment to move heavy objects from high to low (e.g., vehicles, powertrains and high-voltage batteries)

Deactivate

Change operating states of systems/components (e.g., deactivating the alert state of immobilizer system or power-on state of high-voltage system)

Release

Release mechanisms/closed systems from pressure application (e.g., ESP and pressure)

Add

Add gas or liquid to certain space (e.g., transmission fluid and inert gas)

Drain

Discharge gas or liquid from certain space (e.g., transmission fluid and inert gas)

Bleed

Discharge the gas mixed in certain space (e.g., bleeding the brake system)

Recycle

Collect objects that need to be disposed of as specified after maintenance (e.g., recycling refrigerant)

Move aside

Move interfering components aside during maintenance for easy operation (e.g., wiring harnesses)

Press

Press clamping parts before removing or installing connecting mechanisms (e.g., seat belt latches and pipeline joint latches)
