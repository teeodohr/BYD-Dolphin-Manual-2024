System descriptions

Overview

The panoramic view system includes two main functions: 2D panoramic view and transparent panoramic view. In R gear, these functions will be triggered automatically. Users can also activate and enable these functions manually by pressing the hard button on the steering wheel or the APP soft button on the touchscreen homepage. The image is input through four 720P high-definition cameras and transmitted through the LVDS interface at a rate of 30 frames per second.

It is mainly used to provide the user with a reversing image during reversing, to help the user complete parking faster. The user can use this function by turning on APP button on the touchscreen homepage if necessary or by shifting into R gear.
