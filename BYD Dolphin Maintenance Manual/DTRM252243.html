Write EM2EYJ luxury version configuration

  1. Power on the vehicle.

  2. Connect the VDS and tap "Vehicle diagnosis system" to select "Passenger car".

  3. Select the corresponding vehicle series.

  4. Scan.

  5. Select "Safety system (BYD)".

  6. Select "Calibration".

  7. Tap "Write EM2EYJ luxury version configuration".
