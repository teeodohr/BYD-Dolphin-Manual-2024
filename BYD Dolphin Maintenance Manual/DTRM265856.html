Calibration of integrated front drive assembly

Caution
Since the intelligent front drive assembly is integrated with the power domain control module and front drive motor control module, perform the following calibrations 1-5 when replacing the electronic control, and perform calibration 5 only when replacing the drive motor.

  1. Immobilizer matching (password clearing and programming):

    1. Place the key at the immobilizer RF card reader.

    2. Connect the VDS and enter the diagnostic system interface.

    3. Select "Dolphin" model.

    4. Select "Special diagnosis function".

    5. Tap "Immobilizer matching".

    6. Tap "Clear password of motor control unit", and the VDS displays that the password is cleared successfully.

    7. Enter immobilizer matching interface again, select "Motor control unit programming", and tap "Execute", with "Programming successful" displayed.

  2. Inclination calibration

    1. Power on the vehicle and stop it stably to a horizontal position.

    2. Connect the VDS and enter the diagnostic system interface.

    3. Select "Dolphin" model.

    4. Select "Power domain control unit".

    5. Select "Inclination calibration".

    6. Manually conduct inclination calibration.

    7. Read the data flow, and VDS displays "Calibrated" for "Inclination calibration information/Calibration or not".

  3. Vehicle VIN writing and reading

    1. Power on the vehicle.

    2. Connect the VDS and enter the diagnostic system interface.

    3. Select "Dolphin" model.

    4. Select "Power domain control unit".

    5. Vehicle VIN writing and reading

    6. Tap "Vehicle VIN writing".

    7. Identify the vehicle VIN and check that the read VIN is consistent with the real vehicle VIN.

    8. Return to the previous page "VIN writing" and tap "Run".

    9. VDS displays that the writing is successful, and the identified VIN is consistent with the vehicle VIN.

    10. Read the data flow, and the feedback value of "VIN written or not" is "Written".

  4. Cruise configuration calibration

    1. Power on the vehicle.

    2. Connect the VDS and enter the diagnostic system interface.

    3. Select "Dolphin" model.

    4. Select "Power domain control unit" and "Cruise configuration calibration".

    5. Select "Cruise control" or "Adaptive cruise control" based on the model.

    6. Select "Activate calibration".

  5. Zero-position calibration

    Caution

    • When the drive motor controller or drive motor is replaced separately, zero calibration is required. When replacing the assembly, zero calibration is not required.

    • After replacing the drive motor control module or drive motor separately, use VDS to perform the zero calibration according to the following steps: Set the vehicle to ON, or park the vehicle by switching to gear P, connect and start the diagnostic equipment, and select the "Dolphin" model as follows.

    1. Record the motor zero-position barcode (case sensitive).

    2. Connect the VDS and enter the diagnostic system interface.

    3. Select "Front drive motor control unit".

    4. Tap "Motor Zero-position Calibration".

    5. Properly enter the motor zero-position barcode and tap "Confirm". If the barcode is confirmed, "Operation succeeded" will be displayed; if the barcode is wrong, "Negative response" will be displayed.

    6. Power off and restart the vehicle. After successful calibration, check whether the zero-position calibration is successful by VDS data flow reading (i.e. whether the latest zero-position value is the same as the current motor barcode zero-position value).
